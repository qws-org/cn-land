PWA (desktop)

Quick Cache Clearing

  1. 打开已安装的 PWA 像普通应用一样启动它即可。

  2. 按下 F12 或 Ctrl + Shift + I（Windows），或 Cmd + Option + I（MacOS）以打开开发者工具（DevTools）。
  3. 进入 Application（应用） 标签 → Clear storage（清除存储） 勾选所有选项（如 Local storage、IndexedDB、Cache storage、Service Workers 等） 点击 “Clear site data（清除网站数据）”

  4. 刷新应用程序（按 Ctrl + R 或 F5） 完成后，所有本地数据（包括缓存和旧版本的 Service Worker）将被删除，PWA 将从零开始重新加载。
